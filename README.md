# Yatin Danani - Developer Portfolio

🚀 **Live Demo:** [https://yatindanani.github.io](https://yatindanani.github.io)

An Apex Legends-themed portfolio website showcasing my projects, skills, and experience as a Computer Science & Mathematics student at the University of Victoria.

## ✨ Features

- **Apex Legends-Inspired Design**: Futuristic, tactical aesthetic with signature red and purple color scheme
- **Fully Responsive**: Optimized for all devices from mobile to desktop
- **Animated Interactions**: Smooth scroll animations, hover effects, and transitions
- **Project Showcase**: Interactive horizontal carousel with project cards and direct links to code and live demos
- **Tech Stack Display**: Comprehensive overview of programming languages, frameworks, and tools
- **Contact Integration**: Direct links to GitHub, LinkedIn, and email

## 🎨 Design Highlights

- Custom Orbitron and Rajdhani fonts for authentic gaming aesthetic
- Gradient borders and clip-path polygons for angular Apex-style frames
- Scanline overlay effects and animated corner accents
- Responsive grid layouts with CSS Grid

## 🛠️ Tech Stack

**Frontend:**
- HTML5
- CSS3 (Advanced animations, clip-path, gradients)
- Vanilla JavaScript

**Design:**
- Custom Google Fonts (Orbitron, Rajdhani)
- CSS Grid & Flexbox

## 🚀 Deployment

This portfolio is deployed on **GitHub Pages** and is accessible at:
**[https://yatindanani.github.io](https://yatindanani.github.io)**

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/YatinDanani/YatinDanani.github.io.git
```

2. Navigate to the project directory:
```bash
cd YatinDanani.github.io
```

3. Open `index.html` in your browser:
```bash
open index.html
```

## 🎯 Key Features

- **Single File Architecture**: All CSS and JavaScript embedded in one HTML file for easy deployment
- **No Build Process**: Pure HTML/CSS/JS - no frameworks or dependencies required
- **Fast Loading**: Optimized for performance with minimal external resources
- **SEO Friendly**: Proper meta tags and semantic HTML structure
